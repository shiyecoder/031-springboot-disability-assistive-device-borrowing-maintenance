# NEW-031 设计系统 · 理性学院蓝

## 视觉方向
面向社区康复驿站的专业业务系统：数据可读性优先，操作效率优先，状态辨识优先。
不使用巨幅英文口号、装饰性光效、悬浮球、过度渐变或大面积插画。卡片圆角 6–8px，阴影仅用于抽屉与弹窗。

## 色彩
| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | #173B57 | 顶部栏、主按钮、当前菜单、关键数字 |
| 辅助色 | #287271 | 次级按钮、筛选选中态、普通图表系列 |
| 页面背景 | #F4F7F9 | 主内容区，表格与表单用白色容器 |
| 强调色 | #2F6B8A | 链接、信息提示、图表对比系列 |
| 成功 | #287D4F | 已完成 / 已通过 / 正常 |
| 危险 | #B42318 | 驳回、超时、异常、删除确认（小面积） |
| 边框 | #DCE3E8 | 卡片、表格、输入框 |
| 主文本 | #1C2B36 | 正文 |
| 次文本 | #5F707C | 标签、说明、辅助信息 |

图表色从主色/辅助色/强调色/中性灰派生，同一含义跨页一致。状态不靠颜色单独表达，必须带中文标签。

## 字体阶梯
- 页面标题 20px / 600
- 卡片标题 14px / 600
- 正文与表格 14px / 13px
- 辅助说明 12px
- 关键指标 24–34px / 600
- 数字列启用 `font-variant-numeric: tabular-nums`
- 字体栈：PingFang SC → Microsoft YaHei → system-ui

## 布局
- 左侧菜单 220px（折叠保留图标 + 悬浮说明），顶部栏 56px，内容区 24px 外边距
- 表单标签 100–120px，单列输入 360–520px，搜索下拉 180–240px
- 常用操作不超过三级层级；行内最多「查看 + 2 个高频操作」，其余进「更多」

## 组件规范
- 按钮：高 34px（小号 28px），圆角 6px，主按钮填充 #173B57，危险操作红色描边 + 二次确认
- 输入框：高 34px，边框 #DCE3E8，聚焦 1px #2F6B8A + 2px 淡光
- 表格：表头 #F7FAFB / 600，行高 44px，表头不写死宽度，编号/状态/日期/操作列单行
- 卡片：白底 + 1px 边框 + 8px 圆角，内边距 18px，卡片间距 16px
- 标签：高 22px，圆角 10px，语义色 8% 透明度底 + 实色文字
- 分页：默认 10 条，可切 20/50，切换筛选条件回到第 1 页
- 空状态：说明产生原因 + 下一步操作

## 无障碍
- 正文最小 13px，对比度 ≥ 4.5:1；点击区域 ≥ 44px（移动端）
- 表单错误提示置于字段下方，红字 + 图标，不用仅颜色区分
- 加载超 300ms 显示局部骨架或表格加载态，禁止整页白屏
